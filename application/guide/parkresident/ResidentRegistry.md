#Жилой комплекс.
Жилой комплекс является логической сущностью для формировании группы парковочных площадок.  
В рамках одного жилого комплекса может быть несколько парковочных площадок.  
#Парковочная площадка
Парковочная площадка - это территория, предназначенная для размещения транспортных средств.  
Основные параметры парковочной площадки:  
1. название.  
2. количество машиномест для парковки.  
3. перечень точек въезда.  
4. перечень точек выезда.  
5. режим работы: с учетом направления проезда или без учета направления проезда.  
Парковочная площадка может входить только в один жилой комплекс.
#Машиноместо
Машиместо - минимальная территория, предназаченная для парковки транспорного средства.
Машиноместо входит в парковочную площадку.  
#Гараж.
Гараж - несколько машиномест, объеденных в одну группу.  
Одно машиноместо может входить только в одну группу.
